
# A1 Hindi AI Shorts

Automated Hindi AI story Shorts (30–45 seconds).

## Goals
- 2 original Hindi story videos daily
- YouTube Shorts
- Instagram Reels
- Facebook Reels
- Automated publishing using GitHub Actions

## Workflow
1. Generate Hindi stories.
2. Create scene visuals.
3. Generate Hindi voiceover.
4. Render vertical videos with captions.
5. Publish through official platform APIs.

## Security
Store API keys in GitHub Actions Secrets.
Never publish passwords or access tokens.
